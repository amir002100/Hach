# HappNG

HappNG is an Android client project for managing proxy profiles and subscriptions.

## Status

Initial Android project scaffold. The first milestone is a reproducible debug APK build through GitHub Actions. Real VPN tunneling requires the Xray core integration and device-level validation; it is not claimed complete in this scaffold.

## Build

Push to `main` or run the **Android APK** workflow manually. The workflow builds the debug APK and uploads it as an artifact.
